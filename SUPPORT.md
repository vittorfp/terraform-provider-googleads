# Support

This project is maintained on a best-effort basis. There is no service-level
agreement and no guaranteed response or resolution time.

## Community support

Use GitHub Issues for reproducible provider bugs, documentation problems, and
feature requests that could benefit the wider community. Issues are reviewed
as maintainer availability allows.

Before opening an issue:

- use the latest released provider version;
- search existing issues and the backlog;
- reduce the problem to the smallest configuration that still reproduces it;
- remove credentials, customer IDs, resource names, request IDs, URLs, ad copy,
  Terraform state, and generated account exports;
- identify the Terraform or OpenTofu version and Google Ads API access path.

An automated reply confirms that a new issue entered the triage queue. It is
not a technical diagnosis or a promise that the issue will be implemented.

## Scope

Community support covers the latest released minor version. Older versions may
be asked to upgrade before a report is investigated. Feature requests are
prioritized by general usefulness, maintainer capacity, and whether a
contributor is available to implement them.

Account-specific setup, private campaign debugging, migration projects, custom
resources, and urgent production assistance are outside the community support
commitment.

## Security and sensitive data

Do not post credentials or customer data in an issue, discussion, pull request,
or log attachment. For vulnerabilities or accidental exposure, use GitHub's
private vulnerability reporting flow described in [SECURITY.md](SECURITY.md).
